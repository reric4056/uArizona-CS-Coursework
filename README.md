## About This Repository

This repository serves as an archive of my undergraduate computer science coursework at the University of Arizona.

It documents my progression from introductory programming and object-oriented design to advanced topics including data structures, algorithms, computer architecture, systems programming, parallel and distributed computing, statistical analysis, and machine learning.

The projects reflect my academic experience working with Python, Java, C, and MIPS Assembly, as well as my exposure to software development practices, algorithmic problem-solving, and computational experimentation.

My goal is to preserve these assignments while providing an organized record of the technical concepts and programming skills I developed throughout my undergraduate education.

Some projects are complete implementations, while others are theoretical analyses, partial implementations, or exercises developed using instructor-provided frameworks. Unless otherwise noted, the files are preserved primarily in their original academic form.

#### Iris Classification

Developed classification experiments using Fisher's Iris Dataset.

Compared individual features, feature combinations, multiclass logistic regression, and a support vector machine with an RBF kernel.

**Topics demonstrated:**
- Supervised Classification
- Feature Selection
- Cross-Validation
- Hyperparameter Optimization
- Decision Boundary Visualization
- Confusion Matrices
- Precision, Recall, and F1-Score

**Reported Logistic Regression Test Accuracy: 97.37%**

#### Online Sexism Detection

CSC 380 final project based on SemEval 2023 Task 10: Explainable Detection of Online Sexism.

Implemented binary text classification using two feature extraction methods and three classification algorithms.

**Feature Extraction:**
- Bag-of-Words
- TF-IDF
- Unigrams and Bigrams

**Classification Algorithms:**
- Logistic Regression
- Linear Support Vector Machine
- Multinomial Naive Bayes

Six feature/model combinations were evaluated.

**Best Reported Weighted F1-Score: 0.787**

The original evaluation selected the strongest configuration using test-set results. This methodological limitation is documented as part of the preserved coursework.
